# 0.9.6 — Chromink · 描彩

独立仓库发布，更新应用名称、主页、命令行帮助及 Windows 可执行文件名。保留原有配置和文件库兼容性。

# 0.9.5

- 分组边框改为更清晰的 2px；跨行采用行尾右侧、续行左侧开口，避免连接线混入其他文件。
- 文件库及其底部按钮取消鼠标光晕。
- 恢复连续网格排列，分组和 PDF 外框沿跨行范围包裹，不再另起一行；跨行使用边缘开口表示延续。

# 0.9.4

- 鼠标光晕直径减半。
- 展开分组和 PDF 使用覆盖标题卡片及全部子图的整体外框，组外文件从下一行继续。

# 0.9.3

- 统一圆形按钮和胶囊外沿，取消悬停底色，增加范围内鼠标跟随光晕。
- 文件库移除底部黑条、文件扩展名和普通卡片边框；PDF 使用专用图标，分组使用叠放缩略图。
- 缩略图默认降低亮度，悬停恢复；仅展开的容器显示外框。

# 0.9.2

- 胶囊使用柔和圆角外沿，移除内部按钮单独边框，统一弹出面板边缘。
- Logo 提示单独加宽，主页网址完整显示在一行。

# 0.9.1

- 新文件继承当前参数；索引图片读取调色板色数限制上限，结果白底默认开启。
- 文件库改为右下角添加与清空按钮，操作提示统一集中到 Logo。
- 统一半透明表面和框线，移除光影；悬停时固定胶囊起点，移开后恢复居中。
- Logo 提示末尾显示版本和主页，取消双击主页操作。

# 0.9.0

- 底栏整理为基础、减色、描摹/保存三组 40px 胶囊。
- 根据当前描摹方式显示 Potrace 或 Vecline 参数；Vecline 只保留七项关键控制。
- 增加 Vecline 曲线、自动、像素矩形、精确轮廓模式及七个图像预设，衔接独立色数/减色流程。
- 两种 Lloyd 减色只提供迭代及必要单色阈值控制，界面其他参数使用默认值。
- 清理旧 Python 实现、实验和历史报告、测试代码及退役的 Quantette 小批量 K-means；保留当前代码和完整版权许可。
- 同一 EXE 无头命令同步精简，模式/预设与关键参数具备 help 和 JSON schema。

清理前通过 68 项 Rust 验证和 7 组界面验证；清理后重新构建并验证发布 EXE。Windows x64 为本次验证的平台。
